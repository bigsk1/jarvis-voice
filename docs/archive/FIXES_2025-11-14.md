# Fixes Applied - 2025-11-14

## Issues Fixed

### 1. ✅ Database Auto-Creation
- **Issue:** Database wasn't being created automatically on first run
- **Fix:** Database creates correctly now, verified with 44KB file creation

### 2. ✅ Conversation Logging Error  
- **Issue:** `'LLMRouter' object has no attribute 'config'`
- **Root Cause:** Router class doesn't have a `config` attribute
- **Fix:** 
  - Changed `self.router.config.get("mode")` → `self.mode` (orchestrator has it)
  - Added `provider_type` and `model_name` attributes to router
  - Used safe `getattr()` with defaults

### 3. ✅ Token/Usage Info in Response
- **Issue:** Usage info not included in JSON output
- **Fix:** Added `usage` field to response when available (cloud only)
  ```json
  {
    "speech": "...",
    "ok": true,
    "usage": {
      "input_tokens": 9676,
      "output_tokens": 83,
      "cost_usd": 0.030273
    }
  }
  ```

### 4. ✅ Intel Ingestion Timeout
- **Issue:** `ingest_intel` tool timing out after 15 seconds
- **Root Cause:** Embedding generation takes longer than standard tools
- **Fix:** Increased timeout to 60 seconds for `ingest_intel` tool

### 5. ✅ Local Mode with --json Flag Hanging
- **Issue:** Local mode completely froze when using `--json` flag
- **Root Cause:** Duplicate `except` blocks in router causing syntax/logic error
- **Fix:** Removed duplicate except block, fixed try/except structure

### 6. ✅ Test Script Model References
- **Issue:** Test script checking for old `mistral-nemo` model
- **Fix:** Updated all references to `qwen3-vl`
