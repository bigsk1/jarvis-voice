Allow the microphone for Talk

Click below and choose Allow in Firefox. Keep “Remember this decision” selected to avoid another prompt on each turn.

Keep this tab open while using Talk in the sidebar. Firefox needs a regular extension tab to open the microphone reliably. The sidebar keeps your conversation and Talk controls.

Starting or resuming sidebar Talk briefly selects this tab to open the microphone, then returns to your previous tab. It stays in the background during your conversation.

This permission check stops capture immediately and sends no audio. Afterward, only an explicit Talk session uses the microphone. Pause or End in the sidebar stops it. Closing this tab pauses sidebar Talk.
