Add files to library PDF, Markdown, text · multiple files or server inbox

Choosing files only puts them on this list. Click Add to library to save the originals and index their text in the library database for retrieval. This does not copy files into the server inbox. Each file: up to 25 MB and 1,000,000 extracted characters. You can search its text once added. Scanned pages need separate OCR; originals remain until deleted.

Large offline import

Place files in the mode-specific library inbox on the server or Docker data mount, then queue them here. Import and meaning indexing continue if this tab closes. Files remain in the inbox after import.
