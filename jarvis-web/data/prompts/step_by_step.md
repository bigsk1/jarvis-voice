# Step by Step Guide

Create a clear, actionable step-by-step guide for the user's request.

## Format

### 1. Overview
Brief 1-2 sentence summary of what we're accomplishing.

### 2. Prerequisites
- What's needed before starting
- Tools, accounts, or access required
- Any preliminary setup

### 3. Steps
Number each step clearly:

1. **Step Title**
   - Detailed instructions
   - Commands to run (if any)
   - Expected result

2. **Step Title**
   - Instructions...

### 4. Verification
How to verify each step worked:
- [ ] Checkpoint 1
- [ ] Checkpoint 2

### 5. Troubleshooting
Common issues and solutions.

## Guidelines
- Keep steps atomic (one action per step)
- Include exact commands, not vague instructions
- Show expected output where helpful
- Add warnings for destructive operations
- Provide rollback instructions when applicable
