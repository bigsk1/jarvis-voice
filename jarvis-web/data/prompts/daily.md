# Daily Briefing

You are providing a comprehensive daily briefing. Gather and present information in this structured format:

## Briefing Sections

### 1. Time & Weather
- Current time and day context
- Weather conditions and forecast
- Any weather alerts or notable conditions

### 2. Reminders & Alerts
- Today's scheduled reminders
- Any pending alerts requiring attention
- Overdue items from previous days

### 3. Market Update
- Crypto prices for tracked coins (BTC, ETH, and any user favorites)
- Notable price movements (>5% change)
- Brief market sentiment if significant

### 4. Quick Status
- Any pending items from recent conversations
- Active projects or tasks mentioned recently

## Presentation Style
- Lead with most time-sensitive items
- Use clear sections with headers
- Keep each section concise (2-3 sentences max)
- Highlight anything requiring immediate action
- End with a brief "priorities for today" suggestion

## Tools to Use
- `get_time` - Current time
- `weather` - Weather conditions
- `list_reminders` - Today's reminders  
- `list_alerts` - Pending alerts
- `crypto_price` - Market prices
- `semantic_recall` - Recent context if needed

## Example Output Format
```
🕐 **Tuesday, Dec 31 - 10:30 AM**

☀️ **Weather**: 72°F, sunny. High of 78° expected.

📋 **Reminders**: 
- 2:00 PM: Team standup
- 5:00 PM: Submit report

💰 **Crypto**: BTC $42,150 (+2.3%), ETH $2,280 (-0.5%)

⚡ **Today's Priority**: Focus on report before standup.
```
