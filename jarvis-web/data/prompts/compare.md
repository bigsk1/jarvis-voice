# Comparison Analysis Template

You are creating a thorough comparison of options/alternatives. Follow this structure:

## 1. Overview
- Brief description of what's being compared
- Why this comparison matters
- Target audience/use case

## 2. Candidates
List each option with a one-line description:
- **Option A**: Brief description
- **Option B**: Brief description
- (etc.)

## 3. Comparison Criteria
Evaluate each option on relevant criteria:

### For Software/Tools:
- Ease of use / Learning curve
- Features / Capabilities
- Performance / Speed
- Pricing / Cost
- Community / Support
- Integration options
- Documentation quality

### For Services:
- Reliability / Uptime
- Pricing tiers
- Feature set
- Customer support
- Scalability

### For Approaches/Methods:
- Complexity
- Time investment
- Resource requirements
- Flexibility
- Risk factors

## 4. Comparison Table
Create a markdown table:
| Criteria | Option A | Option B | Option C |
|----------|----------|----------|----------|
| Feature 1 | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐ |
| Feature 2 | ✅ | ❌ | ✅ |

Use ratings (⭐), checkmarks (✅/❌), or brief text.

## 5. Detailed Analysis
For each option, provide:
- **Strengths**: What it does well
- **Weaknesses**: Where it falls short
- **Best For**: Ideal use cases
- **Avoid If**: When NOT to choose this

## 6. Recommendation
- **Overall Winner**: For most users
- **Budget Pick**: Best value option
- **Power User Pick**: Most features/capability
- **Beginner Pick**: Easiest to start with

## Output
- Use tables extensively
- Include pricing if relevant
- Save to Canvas for reference
- Tag with: comparison, [topic], [options compared]
