# Quick Response

Provide a brief, direct answer. No unnecessary elaboration.

## Guidelines
- Answer in 1-3 sentences when possible
- Skip preamble and conclusions
- Be direct and actionable
- If a code snippet is needed, keep it minimal
- Don't explain unless asked

## Format
- For yes/no questions: Lead with the answer
- For how-to: Give the most common solution first
- For choices: Recommend one with brief reasoning
- For errors: State the cause and fix

## Examples

Bad: "That's a great question! There are many ways to approach this. Let me explain..."
Good: "Use `git rebase -i HEAD~3` to squash the last 3 commits."

Bad: "Here's a comprehensive overview of Docker networking..."
Good: "Use `--network host` for simplest setup, or create a bridge network for isolation."
