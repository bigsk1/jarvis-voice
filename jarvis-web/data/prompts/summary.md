# Summarization Guidelines

You are creating a summary. Follow these principles:

## Summary Types

### TL;DR (1-2 sentences)
- Capture the absolute core message
- What would you tell someone in an elevator?

### Executive Summary (1 paragraph)
- Key findings/conclusions
- Most important points only
- Action items if relevant

### Detailed Summary (Multiple paragraphs)
- All major points covered
- Organized by theme or section
- Preserves important details

## Summarization Process

### 1. Identify the Purpose
- What type of content is this?
- Who is the audience?
- What decisions will this inform?

### 2. Extract Key Information
- Main thesis or argument
- Supporting evidence/data
- Conclusions reached
- Action items or recommendations

### 3. Prioritize Content
- What MUST be included?
- What's nice-to-have?
- What can be cut entirely?

### 4. Structure the Summary
- Lead with the most important point
- Use bullet points for lists of items
- Group related information
- End with conclusions/next steps

## Format Guidelines

### For Documents/Articles:
```
## Summary
[1-2 sentence TL;DR]

## Key Points
- Point 1
- Point 2
- Point 3

## Details
[Expanded information organized by topic]

## Takeaways
- Action item 1
- Action item 2
```

### For Meetings/Conversations:
```
## Meeting Summary
**Date**: [date]
**Participants**: [who]
**Purpose**: [why]

## Decisions Made
- Decision 1
- Decision 2

## Action Items
- [ ] Task 1 - Owner - Due date
- [ ] Task 2 - Owner - Due date

## Key Discussion Points
- Topic 1: [summary]
- Topic 2: [summary]
```

### For Code/Technical:
```
## What This Does
[1 sentence description]

## How It Works
[Brief technical explanation]

## Key Components
- Component 1: purpose
- Component 2: purpose

## Usage
[Example of how to use it]
```

## Quality Checklist
- [ ] Could someone understand the core message without reading the original?
- [ ] Is it significantly shorter than the original?
- [ ] Are all critical points preserved?
- [ ] Is it well-organized and scannable?
- [ ] Does it avoid editorializing (unless asked)?
