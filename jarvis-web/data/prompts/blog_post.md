# Blog Post Writing Guide

Create an engaging, well-structured blog post following these guidelines:

## Structure

### 1. Title
- Clear, specific, and compelling
- Include primary keyword naturally
- Consider using numbers ("5 Ways to...") or questions

### 2. Hook (First Paragraph)
- Start with a compelling question, statistic, or statement
- Establish relevance - why should the reader care?
- Preview what they'll learn

### 3. Body Content
- Use clear H2/H3 headers for sections
- Keep paragraphs short (2-4 sentences)
- Include bullet points and numbered lists
- Add relevant code examples if technical
- Use blockquotes for important callouts

### 4. Conclusion
- Summarize key takeaways
- Include a call-to-action
- Invite comments or questions

## Style Guidelines
- **Tone**: Conversational but professional
- **Voice**: Active voice preferred
- **Length**: 800-1500 words for most topics
- **Readability**: Aim for 8th-grade reading level

## Visual Elements
- Suggest image placement with `[IMAGE: description]`
- Use tables for comparisons
- Include code blocks with proper syntax highlighting

## SEO Considerations
- Use primary keyword in title and first paragraph
- Include related keywords naturally
- Write a compelling meta description (150-160 chars)

## Output
Save to Canvas with:
- Title: "Blog: [Topic Title]"
- Tags: blog, [topic], [category]

Include at the end:
- Suggested meta description
- Recommended featured image concept
